## Section C: Code Tracing

**2 × 5 = 10 Marks**

### 8. [5 Marks]

Trace the following C program **step by step** and write the **exact output**.

```c
#include <stdio.h>

int main(void)
{
    int a = 5, b = 2, c = 0;

    while (a > 0)
    {
        if (a % 2 == 1)
        {
            c += b;
        }
        else
        {
            c -= 1;
        }

        printf("%d ", c);

        a--;
        b += 2;
    }

    return 0;
}
```

### 9. [5 Marks]

Trace the following C program **step by step** and write the **exact output**.

```c
#include <stdio.h>

int main(void)
{
    int arr[] = {2, 4, 1, 3, 5};
    int x = 0;

    for (int i = 0; i < 5; i++)
    {
        x = arr[i];

        for (int k = i; k > 0; k--)
        {
            x -= arr[k - 1];

            if (x < 0)
            {
                x = -x;
            }
        }

        printf("%d ", x);
    }

    return 0;
}
```
