## Section C: Code Tracing

**2 × 5 = 10 Marks**

### 8. [5 Marks] — Code Tracing

Trace the following C program **step by step** and write the **exact output**.

```c
#include <stdio.h>

int func(int n)
{
    return n % 5;
}

int main(void)
{
    int arr[] = {12, 19, 24, 31};

    for (int i = 0; i < 4; i++)
    {
        int x = func(arr[i]);

        if (x == 4)
        {
            printf("%d ", arr[i] - x);
        }
        else if (x <= 2)
        {
            printf("%d ", arr[i] + x);
        }
        else
        {
            printf("%d ", x);
        }
    }

    return 0;
}
```

### 9. [5 Marks] — Code Tracing

Trace the following C program **very carefully** and write the **exact output**. Show the important intermediate values of `i`, `j`, `total`, and `i + j`.

```c
#include <stdio.h>

int main(void)
{
    int total = 0;

    for (int i = 0; i < 3; i++)
    {
        for (int j = 2; j >= 0; j--)
        {
            if ((i + j) % 2 == 0)
            {
                total += i;
                printf("%d ", total);
            }
            else
            {
                total += j;
                printf("%d ", total);
            }

            if (total > 3)
            {
                printf("%d ", i + j);
            }
        }
    }

    return 0;
}
```
