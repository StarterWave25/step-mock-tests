## Section C — Code Tracing

**2 × 5 = 10 Marks**

### Q8. Function + Conditional Update [5 Marks]

Trace the following C program and write the **exact output**, showing the value of `x` after each iteration.

```c
#include <stdio.h>

int change(int n)
{
    if (n % 4 == 0)
        return n / 2;
    else
        return n + 3;
}

int main()
{
    int x = 7;

    for (int i = 0; i < 4; i++)
    {
        x = change(x - i);

        if (x % 2 == 0)
            x = x + i;
        else
            x = x - 1;

        printf("%d ", x);
    }

    return 0;
}
```

### Q9. Nested Loop + Array + Changing Total [5 Marks]

Trace the following program and write the **exact output**.

```c
#include <stdio.h>

int main()
{
    int a[] = {3, 1, 4};

    for (int i = 0; i < 3; i++)
    {
        int total = 0;
        for (int j = 0; j <= i; j++)
        {
            total = total + a[j];

            if (total % 2 == 0)
                total = total - i;
            else
                total = total + j;

            printf("%d ", total);
        }
    }

    return 0;
}
```
