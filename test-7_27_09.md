## Section C: Code Tracing

### 8. [5 Marks]

Trace the following C program **step by step** and write the **exact output**.

```c
#include <stdio.h>

int main(void)
{
    int x = 3;
    int y = 2;

    for (int i = 0; i < 4; i++)
    {
        if (i % 2 == 0)
        {
            x += y;
        }
        else
        {
            y += i;
        }

        printf("%d %d ", x, y);
    }

    return 0;
}
```

### 9. [5 Marks]

Trace the following C program **very carefully** and write the **exact output**.

```c
#include <stdio.h>

int main(void)
{
    int arr[] = {2, 5, 3, 4};
    int value = 1;

    for (int i = 0; i < 4; i++)
    {
        value += arr[i];

        if (value % 2 == 0)
        {
            for (int j = i; j >= 0; j--)
            {
                value -= j;
            }
        }
        else
        {
            value += i;
        }

        printf("%d ", value);
    }

    return 0;
}
```
