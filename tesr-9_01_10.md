## Section C: Code Tracing

**2 × 5 = 10 Marks**

### 8. [5 Marks]

Trace the following C program and write the **exact output**.

```c
#include <stdio.h>

int change(int n)
{
    if (n % 3 == 0)
        return n / 3;
    else
        return n + 2;
}

int main(void)
{
    int x = 4;

    for (int i = 0; i < 4; i++)
    {
        x = change(x + i + 2);

        if (x % 2 == 0)
            x -= i;
        else
            x += i + 1;

        printf("%d ", x);
    }

    return 0;
}
```

### 9. [5 Marks]

Trace the following C program **very carefully** and write the **exact output**.

```c
#include <stdio.h>

int main(void)
{
    int arr[] = {2, 5, 1};
    int total = 0;

    for (int i = 0; i < 3; i++)
    {
        for (int j = 2; j >= i; j--)
        {
            total += arr[j];

            if (total > 6)
                total -= i + j;
            else
                total += j;

            printf("%d ", total);
        }
    }

    return 0;
}
```
