# Section C — Code Tracing

**2 Questions × 5 Marks = 10 Marks**

### Q8. Pattern Breaker — `continue` + Changing Variable [5 Marks]

Trace the following program and write the **exact output**.

```c
#include <stdio.h>

int main()
{
    int x = 1;

    for (int i = 1; i <= 6; i++)
    {
        x += i;

        if (x % 2 == 0)
        {
            x /= 2;
            continue;
        }

        x += i;

        if (x > 10)
            x -= 3;

        printf("%d ", x);
    }

    return 0;
}
```

Be careful: when `continue` executes, the remaining statements in that iteration are skipped.

### Q9. Pattern Breaker — Array Values Affect Future Iterations [5 Marks]

Trace the program and write the **exact output**.

```c
#include <stdio.h>

int main()
{
    int a[] = {3, 5, 2, 6};
    int x = 0;

    for (int i = 0; i < 4; i++)
    {
        x += a[i];

        if (x % 2 == 0)
        {
            a[i] = a[i] - 1;
            x += a[i];
        }
        else
        {
            a[i] = a[i] + 2;
            x -= a[i];
        }

        if (i > 0)
            a[i] = a[i] + a[i - 1];

        printf("%d ", x);
    }

    return 0;
}
```

**Trace both `x` and the modified array values.**
