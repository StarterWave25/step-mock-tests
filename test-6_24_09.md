## Section C: Code Tracing

**2 × 5 = 10 Marks**

### 8. [5 Marks]

Trace the following C program **step by step** and write the **exact output**.

```c
#include <stdio.h>

int main(void)
{
    int x = 2;
    int y = 10;

    do
    {
        if (y % x == 0)
        {
            printf("%d ", y / x);
            y -= x;
        }
        else
        {
            printf("%d ", y);
            y--;
        }

        x++;
    }
    while (x <= 5);

    return 0;
}
```

### 9. [5 Marks]

Trace the following C program **very carefully** and write the **exact output**.

```c
#include <stdio.h>

int main(void)
{
    int a[] = {3, 1, 4, 2};
    int result = 0;

    for (int i = 0; i < 4; i++)
    {
        for (int j = i; j < 4; j++)
        {
            if (a[j] > a[i])
            {
                result += a[j] - a[i];
            }
            else
            {
                result += a[i] - a[j];
            }

            if (result % 4 == 0)
            {
                printf("%d ", result);
            }
        }
    }

    return 0;
}
```
