# Section C — Code Tracing

### Q8. Code Tracing — Function + Loop-Control Change [5 Marks]

Trace the following C program and write the **exact output**.

```c
#include <stdio.h>

int change(int n)
{
    if (n % 2 == 0)
        return n / 2;
    else
        return n + 3;
}

int main()
{
    int x = 5;

    for (int i = 0; i < 5; i++)
    {
        x = change(x + i);

        if (x > 8)
            i++;

        x = x - i;

        printf("%d ", x);
    }

    return 0;
}
```

**Trace carefully:** `i` can be modified inside the loop as well as by the `for` statement.

### Q9. Code Tracing — Nested Loop + Array Mutation [5 Marks]

Trace the following program and write the **exact output**.

```c
#include <stdio.h>

int main()
{
    int a[] = {4, 2, 5};
    int total = 0;

    for (int i = 0; i < 3; i++)
    {
        for (int j = 0; j < 3; j++)
        {
            if (j == i)
                continue;

            total += a[j];

            if (total > 7)
            {
                a[j] = a[j] - 2;
                total -= a[j];
            }
            else
            {
                a[j] = a[j] + 1;
            }

            printf("%d ", total);
        }
    }

    return 0;
}
```

**Trace both `total` and the changing array values.**
