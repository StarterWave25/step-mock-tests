## Section C: Code Tracing

**2 × 5 = 10 Marks**

### 8. [5 Marks]

Trace the following C program **step by step** and write the **exact output**.

```c
#include <stdio.h>

int f(int x)
{
    if (x % 2 == 0)
        return x / 2;
    return x * 2;
}

int main(void)
{
    int a = 3;

    for (int i = 1; i <= 4; i++)
    {
        a = f(a + i);

        if (a > 10)
            a -= i;
        else
            a += i;

        printf("%d ", a);
    }

    return 0;
}
```

### 9. [5 Marks]

Trace the following C program **very carefully** and write the **exact output**.

```c
#include <stdio.h>

int main(void)
{
    int arr[] = {3, 1, 4};
    int total = 0;

    for (int i = 0; i < 3; i++)
    {
        for (int j = 0; j <= i; j++)
        {
            total += arr[j];

            if (total % 2 == 0)
                total /= 2;
            else
                total += i;

            printf("%d ", total);
        }
    }

    return 0;
}
```
